# Contribuir

Gracias por mejorar Micro Open Source.

1. Crea una rama desde `main`.
2. Mantén los cambios centrados en macOS y Apple Silicon.
3. Comprueba `python3 -m py_compile dictado.py`.
4. No incluyas modelos, entornos virtuales, audio, historiales ni logs.
5. Abre un pull request explicando el comportamiento anterior y el nuevo.

Para errores, indica la version de macOS, el modelo de Mac, el atajo configurado y el mensaje relevante del log. Elimina cualquier transcripcion personal antes de compartirlo.
